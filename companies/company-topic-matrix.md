# Company-topic preparation map

This is a topic-planning heuristic, not a verified question-frequency ranking. Interview loops vary by role, location, and level.

| Company | Core revision | Deeper practice |
|---|---|---|
| Microsoft | Arrays, strings, hashing, linked lists, trees, graphs | DP, OOP and clear trade-off explanations |
| Amazon | Arrays, strings, trees, heaps, graphs, intervals | Greedy, DP, complexity and edge cases |
| Google | Arrays, graphs, binary search, trees, DP | Correctness arguments and optimization |
| Meta | Arrays, strings, hashing, trees, graphs, intervals | Timed pattern recognition and follow-ups |
| Atlassian | Arrays, trees, graphs, practical problem solving | API/OOP reasoning when role-relevant |
| Adobe | Strings, linked lists, trees, stacks, DP | Recursion, graphs and core CS concepts |
| Uber | Hashing, heaps, graphs, intervals | Graph search and real-world constraints |
| Accenture | Arrays, strings, searching, sorting, hashing | Recursion, trees and complexity basics |
| Target | Arrays, strings, hashing, trees | Practical coding and role-specific design |
| ZS Associates | Arrays, sorting, searching, hashing | Quantitative reasoning; SQL/data topics when relevant |

## How to use this map

1. Pick a topic and solve an unseen Easy problem without hints.
2. Solve a Medium variant and explain the invariant out loud.
3. Re-test the solution with empty inputs, duplicates, boundaries, and adversarial cases.
4. Record wrong approaches and revisit them after a few days.
5. Treat an employer tag as a revision cue, not a guarantee that the company asks the exact prompt.

For canonical statements and additional practice, consult [LeetCode](https://leetcode.com/), [GeeksforGeeks](https://www.geeksforgeeks.org/), [NeetCode](https://neetcode.io/roadmap), [Tech Interview Handbook](https://www.techinterviewhandbook.org/), and [HackerRank](https://www.hackerrank.com/). Each solution file uses a source link where a canonical problem is known and provides an original summary and implementation.
