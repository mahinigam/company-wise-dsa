# Company-Wise DSA

A curated Python interview-practice library organized by algorithmic topic, difficulty, and target company.

**Companies:** Microsoft, Amazon, Google, Meta, Atlassian, Adobe, Uber, Accenture, Target, and ZS Associates.

> Company tags are preparation guidance, not a guarantee that a problem was asked by a particular employer. Questions are summarized in original wording. Follow the linked source for the canonical statement, constraints, and attribution.

Every problem solution should provide a clear function, a short problem summary, time/space complexity, example assertions, and an external source link where applicable. Keep solutions independent and runnable with Python 3.11+.

## Run examples

```bash
python tests/run_examples.py
```

## Quality principles

- Prefer transparent, idiomatic Python over clever one-liners.
- Include edge cases: empty input, duplicates, boundaries, and degenerate structures.
- State assumptions where a prompt is ambiguous.
- Avoid claiming verified company frequency without a reliable source.
- Don't copy full proprietary problem statements or third-party editorials; write original summaries and explanations.
